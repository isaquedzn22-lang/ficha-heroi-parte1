# Neon Realm — Field Dossier Edition

Redesign integral da interface do site, preservando a estrutura HTML, o conteúdo e as funcionalidades do JavaScript original.

## Executar
Abra `index.html` no navegador. Não exige instalação nem servidor.

## Direção de arte
Interface editorial industrial: papel off-white, tipografia condensada, acentos laranja, imagem em destaque como capa, seções que lembram fichas técnicas e catálogo de equipamento. Layout adaptado a dispositivos móveis. O botão de tema continua funcionando.

## Funcionalidades preservadas
Navegação, menu responsivo, alternância de tema, expandir biografia, XP/level-up com armazenamento local, barras de atributos, filtros de inventário, conquistas e validação do formulário.

Observação: o formulário original simula envio no navegador e não envia e-mails para um servidor.
